# Airline Management & Integration Platform with Agentforce

Salesforce airline operations project covering Admin, Apex, LWC, Flows, API integrations, Agentforce, and Salesforce DX deployment.

## Tech Stack

- Salesforce Admin & Flows
- Apex & Triggers
- Lightning Web Components (LWC)
- Aviationstack Flight API
- DummyJSON Payment API
- Agentforce
- Salesforce CLI, Git & GitHub
